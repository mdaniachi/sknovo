# Logos dos Clientes

Coloque aqui os arquivos SVG/PNG das logos dos clientes, nomeados assim:

- `novo-nordisk.svg`
- `play2learn.svg`
- `santos-fc.svg`

Tamanho ideal: altura máxima 80px (a página redimensiona automaticamente).

Cada página de case já tem o bloco HTML pronto. Para ativar a logo, basta:

1. Salvar o arquivo nesta pasta com o nome acima
2. Na página do case, descomentar a linha `<img ...>` dentro do `.client-logo-plate`
3. Apagar o `<span class="client-logo-name">Nome do Cliente</span>` (fallback)
